# Editor notes — Wikipedia drug drafts

These notes tell the copywriter what each draft file is, where it goes on
Wikipedia, what is already done, and what still needs work before posting.

There are **two kinds** of file in the parent folder:

| File | Type | Action |
|---|---|---|
| `wikipedia-draft-etavopivat.txt` | **New article** | Submit via Articles for Creation |
| `wikipedia-draft-fianlimab.txt` | **New article** | Submit via Articles for Creation |
| `wikipedia-addition-vorolanib-EYP-1901.txt` | **Section add-on** | Paste into the *existing* Vorolanib article |
| `wikipedia-addition-thymosin-beta-4-RGN-259.txt` | **Section add-on** | Paste into the *existing* Thymosin beta-4 article |

## How to submit a NEW ARTICLE (etavopivat, fianlimab)

1. Log in to Wikipedia. Go to `https://en.wikipedia.org/wiki/Draft:Etavopivat`
   (or `Draft:Fianlimab`) and click "Create".
2. Paste the full contents of the `.txt` file.
3. Add `{{subst:submit}}` on its own line at the very top.
4. Save. A reviewer will accept it into the main encyclopedia or leave
   comments asking for changes.

## How to apply a SECTION ADD-ON (vorolanib, thymosin beta-4)

1. Open the existing article and click "Edit source".
2. Paste the section into the spot described in the header comment at the
   top of the `.txt` file (the `<!-- ... -->` block).
3. Use an edit summary like: "Add section on EYP-1901 ophthalmic
   development; sources in section".
4. Save. This is a normal edit to a live article — no AfC review.

## Rules that apply to ALL of these

- **Do not add references to hipa.ai, or to any company/marketing site as a
  source for medical facts.** Wikipedia's medical-sourcing rules (WP:MEDRS)
  will get them removed and can flag the account. Every citation in these
  drafts is already a primary/secondary source (journals, FDA, registries,
  trade press) — keep it that way.
- **Click every external link before posting.** All journal data (DOIs,
  PMIDs, authors, page numbers) has been verified, but the press-release and
  news URLs were not all reachable for automated checking. A dead or
  mismatched link is the most common reason a draft gets declined.
- **Keep the neutral tone.** No "groundbreaking", "promising", "revolutionary".
  State what happened and cite it.
- See the per-article note files in this folder for specifics.
